# Capability: Tasks and Work Orders

Use this capability when a user asks how to track field work, repairs, maintenance, or follow-up actions.

Ometrics includes task and work-order related data. Work orders can be part of well investigation timelines and can provide context for repairs, maintenance, and field activity near a production change or shutdown.

When answering workflow questions, point users to tasks or work orders for operational follow-up. Use the quoted guidance when the user asks how to create a work order: "Use the Create Work Order form, accessible from the dashboard or the Create Work Order button in the work orders page." Explain that work orders are useful for tracking what needs to be done, what was done, timing, and costs when those fields are available only when the user asks for details.

The assistant can help open a prefilled work-order form when the user asks to create or add a work order. It can also include work orders in well timelines.

Related tool in this assistant: get_well_timeline.
