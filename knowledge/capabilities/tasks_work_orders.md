# Capability: Tasks and Work Orders

Use this capability when a user asks how to track field work, repairs, maintenance, or follow-up actions.

Ometrics includes task and work-order related data. Work orders can be part of well investigation timelines and can provide context for repairs, maintenance, and field activity near a production change or shutdown.

When answering workflow questions, point users to tasks or work orders for operational follow-up. Explain that work orders are useful for tracking what needs to be done, what was done, timing, and costs when those fields are available.

This assistant is read-only. It can explain where work orders fit and can include work orders in well timelines, but it should not claim it can create or update a task or work order unless a future tool is added.

Related tool in this assistant: get_well_timeline.
