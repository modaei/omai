# Capability: Reports

Use this capability when a user asks what report to use or how to summarize production, sales, injection, gas, water, battery, or transfer data.

Ometrics reports are calculated by the reporting engine from measured field data and configuration. Available report areas include oil production, gas production, water production, oil sales, gas flared, gas vented, gas flared and vented, gas fuel, water injection, water transfer, battery reporting, injection allocation, and production allocation.

When a user asks how to know a value or which report to use, point to the matching report and do not run the report. Keep the answer to maximum two sentences. Ask whether the user wants the assistant to run that report for the stated date range when the report and date range are clear.

Only run a report when the user clearly asks to run, show, calculate, get, or return actual report values, or when the user accepts a previous offer to run a specific report for a specific date range.

Examples: use Production Allocation to attribute production to wells; use Oil Production for oil totals over a date range; use Gas Flared or Gas Flared and Vented for flare/vent reporting; use Water Injection or Injection Allocation for injection volumes.

Report selection examples: for "how to know how much water was injected", point to the Water Injection report. For "how to know how much oil was produced", point to the Oil Production report. For "how to know how much gas was produced", point to the Gas Production report. For "how to know how much oil was sold", point to the Oil Sale report. For "how to know how much gas was flared", point to the Gas Flared report. For "how to know how much water was transferred", point to the Water Transfer report.

Related tools in this assistant: list_available_reports, run_report, compare_report_periods.
